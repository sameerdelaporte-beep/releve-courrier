Pour vos agents IA

Donner votre courrier papier à vos agents IA

Un agent IA ne lit pas une enveloppe. Relève transforme chaque pli en document et en données structurées que vos agents peuvent consulter, classer et traiter.

Voir les formulesQuestions fréquentes

Le courrier papier, dernier trou dans l'automatisation

Vos factures, relevés et courriers administratifs arrivent encore en papier. Tant qu'ils restent dans une boîte aux lettres, vos agents IA ne peuvent ni les lire, ni relancer, ni payer, ni classer. Relève comble ce trou : le papier entre d'un côté, de la donnée sort de l'autre.

Ce que reçoivent vos agents

  • le PDF du pli, avec texte reconnu
  • le type de document, l’expéditeur, la date d’émission
  • les montants, échéances, références de contrat ou de facture, IBAN quand ils figurent sur le document
  • l’état du pli : numérisé, envoyé, original détruit, certificat de destruction

Un webhook à chaque pli, une API pour l'historique

  • webhook signé envoyé dès que le pli est numérisé
  • API pour retrouver un pli, son PDF et ses données
  • clés d’accès limitées : chaque agent ne lit que ce que vous autorisez
  • dépôt automatique dans Google Drive, SharePoint ou votre stockage

Un humain reste dans la boucle

Une extraction automatique peut se tromper. Chaque champ extrait renvoie vers le PDF d'origine, et vous pouvez exiger une validation humaine avant qu'un agent agisse (paiement, résiliation, réponse à une administration).

Cas d'usage

  • Agent comptable : rapproche chaque facture papier du bon de commande et prépare le paiement.
  • Agent juridique : suit les délais des courriers d’huissiers, d’avocats et d’administrations.
  • Agent assistant : prévient le dirigeant, rédige la réponse et la met en brouillon.

Disponible avec la formule Entreprise. Voir aussi notre guide : automatiser le traitement d'une facture papier avec un agent IA.

Questions fréquentes

Puis-je connecter mes agents IA à mon courrier ?

Oui, avec la formule Entreprise : un webhook vous notifie à chaque nouveau pli et une API donne accès au PDF et aux données extraites (expéditeur, type, montant, échéance, références). Vous gardez la main sur ce que chaque agent peut lire.

Mes données sont-elles protégées ?

Les fichiers sont chiffrés au repos et en transit, hébergés dans l'Union européenne, et chaque action est tracée dans un journal visible depuis votre espace. Un accord de traitement des données (RGPD) est signé avec chaque client professionnel. Vous fixez la durée de conservation et pouvez tout exporter ou supprimer.

Les scans ont-ils une valeur juridique ?

Un scan est une copie : sa force probante dépend du document et de l'usage que vous en faites. Relève ne propose pas d'archivage à valeur probante certifiée. Pour les actes, titres et contrats dont vous devez conserver l'original, choisissez la réexpédition de l'original.

Quel est le délai de numérisation ?

24 heures ouvrées à partir de la réception, du lundi au vendredi hors jours fériés. Un pli reçu le vendredi après la relève est numérisé le lundi.
